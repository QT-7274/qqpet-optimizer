# Domain Docs

This repository uses a single-context domain model.

## Before exploring

- Read the root `CONTEXT.md` when it exists.
- Read relevant ADRs under `docs/adr/`.
- Missing files are created lazily by domain-modeling workflows.
- Use canonical terms from `CONTEXT.md`.
- Surface conflicts with existing ADRs explicitly.

## Layout

```text
/
|-- CONTEXT.md
`-- docs/adr/
```
