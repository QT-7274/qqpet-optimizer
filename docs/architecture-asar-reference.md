# ASAR 参考代码架构

## 执行摘要

`qq_pet_asar/` 是原始 Electron 应用 v1.2.4 的解包快照，用于行为比对、功能追踪和移植验证。它不是当前发布入口，也不应作为新功能的默认实现位置。

## 技术栈

该部分保留原 Electron/JavaScript 应用结构、窗口资源、业务脚本与原始 Store 行为。其依赖和运行假设以原应用版本为准，不保证适配当前 Node.js、Electron 或 Ruffle 环境。

## 架构模式

整体仍是 Electron 主进程加多 renderer 窗口结构。当前 `qq-pet-macos/` 从这里继承业务组织方式，但替换或加固了平台兼容、Flash 运行时、存储与隐私相关逻辑。

## 使用边界

- 用于确认原始窗口、状态变化和动作选择行为。
- 用于比较移植版是否遗漏资源或流程。
- 不直接参与当前 GitHub Actions 构建。
- 不应在未同步移植版的情况下单独修复功能。
- 其中原有远程更新、设备标识或遥测实现只作历史参考。

## 数据与接口

原版 Store 主要使用 AES-256-CBC 加密的 `config.json`。Python CLI 保留兼容读取能力，但当前移植版默认使用明文 `config-macos.json`。跨目录不存在运行时调用，集成方式是人工对照。

## 源码结构

入口为 `qq_pet_asar/main.js`，其余目录按原应用的初始化、服务、窗口和资源结构组织。详见 [源码树分析](./source-tree-analysis.md)。

## 开发与部署

该目录不纳入常规开发和发布流程。需要移植原行为时，应先在这里定位对应实现，再以最小修改落入 `qq-pet-macos/` 或 `src/qq_pet/`。

## 测试策略

以差异验证为主：对比相同输入下的状态字段、动作路径、窗口交互和存储结果。实际回归测试应在当前桌面端完成。
